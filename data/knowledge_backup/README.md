# Knowledge PDFs (openly licensed only)

Put 2-3 CC BY academic writing PDFs in this folder.

Start with these CC BY guides:

1. `openstax-writing-guide.pdf`
   - Writing Guide with Handbook (OpenStax)
   - License: CC BY 4.0
   - https://openstax.org/details/books/writing-guide

2. `oregon-writes-open-writing-text.pdf`
   - Oregon Writes Open Writing Text
   - License: CC BY
   - https://open.umn.edu/opentextbooks/textbooks/oregon-writes-open-writing-text

3. `who-teaches-writing.pdf`
   - Who Teaches Writing (Oklahoma State University)
   - License: CC BY
   - https://open.umn.edu/opentextbooks/textbooks/1144

Download the PDFs manually and save them with the filenames above.
Update `manifest.json` if you use different filenames.

Only openly licensed books are ingested. The ingest script refuses
files whose license is not in `allowed_license_prefixes`.
